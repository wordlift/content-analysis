# Security

This repository contains client code and evaluation tooling; it holds no
credentials and never sends your WordLift API key anywhere except to the
`resolve()` endpoint you configure.

If you find a vulnerability in this code, or a way to reach anything other
than the public endpoint through it, please report it privately through
GitHub's "Report a vulnerability" form on this repository rather than in a
public issue. Include a minimal reproduction. You will get an acknowledgement
within a few working days.

Issues with the hosted engine itself (availability, wrong answers) are not
security reports; use the issue templates for those.
